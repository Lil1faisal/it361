=========================================================
 موقع نادي السايبر - الجامعة السعودية الإلكترونية
 مشروع مادة برمجة الويب
=========================================================

التشغيل
-------------------------------------
1. انسخ مجلد club-website داخل:  C:\xampp\htdocs\
2. شغّل Apache من XAMPP.
3. افتح المتصفح على:  http://localhost/club-website/index.php
( لا تفتح الملفات بالضغط المزدوج، لازم localhost عشان PHP يشتغل )


وين تعدّل كل شي   ← مهم
=========================================================

1) اسم النادي، الجامعة، الإيميل، الجوال، أعضاء الفريق
   -> ملف  settings.php
   عدّل السطر بس، وبيتغير تلقائي في كل الصفحات الست.
   مثال:  $club_name = "Cyber Club";

2) الفعاليات (إضافة / حذف / تعديل)
   -> ملف  events_data.php
   لإضافة فعالية: انسخ آخر array وغيّر الـ id والمعلومات.
   ملاحظة: كل array تنتهي بفاصلة إلا الأخيرة.

3) الألوان والخطوط
   -> ملف  style.css
   اللونين المستخدمين مكتوبين في أول الملف بالتعليق.

4) نصوص الصفحات (العناوين والفقرات)
   -> مكتوبة داخل الصفحة نفسها بين وسوم HTML عادية.


الملفات
-------------------------------------
settings.php       الإعدادات: اسم النادي والجامعة والفريق
events_data.php    بيانات الفعاليات (6 فعاليات سايبر)
style.css          التنسيق المشترك
index.php          الرئيسية: تعريف + أقرب 3 فعاليات
events.php         جدول بكل الفعاليات
event.php          تفاصيل فعالية واحدة   event.php?id=3
register.php       فورم التسجيل + التحقق + الحفظ
registrations.php  جدول بكل التسجيلات
about.php          عن النادي + جدول الفريق + فورم التواصل
registrations.txt  الملف اللي تنحفظ فيه التسجيلات


مطابقة المتطلبات
=========================================================
مكتوبة بالتفصيل في ملف   REQUIREMENTS.txt


قبل التسليم
-------------------------------------
- بدّل أسماء أعضاء الفريق في settings.php
- أضف صورة واحدة على الأقل (الركوايرمنت يذكر images)
- لو ما رضي يحفظ التسجيل، أعطِ صلاحية كتابة لملف registrations.txt
