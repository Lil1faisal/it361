 مطابقة المشروع للمتطلبات
 موقع نادي السايبر - الجامعة السعودية الإلكترونية
=========================================================


أولاً: HTML
=========================================================

المطلوب: Valid, semantic markup (header, nav, main, section, footer)
[✔] كل صفحة من الصفحات الست تحتوي على:
    <header>  <nav>  <main>  <section>  <footer>

المطلوب: correct use of headings
[✔] h1  اسم النادي في الهيدر
    h2  عنوان كل قسم
    h3  العناوين الفرعية داخل الأقسام

المطلوب: lists
[✔] ul  في index.php   (قائمة What we do)
    ol  في about.php   (اتجاهات عمل النادي الثلاثة)

المطلوب: tables
[✔] المطلوب جدول واحد على الأقل، وعندنا أربعة:
    events.php         جدول كل الفعاليات
    event.php          جدول معلومات الفعالية
    registrations.php  جدول التسجيلات المحفوظة
    about.php          جدول أعضاء الفريق

المطلوب: images
[ ] لا توجد صور في الموقع حالياً.
    لتغطية هذه النقطة: احفظ أي صورة جنب الملفات وضِف هذا
    السطر في index.php تحت العنوان:
    <img src="logo.png" alt="University logo" width="80">

المطلوب: links
[✔] شريط التنقل في كل صفحة
    روابط Read more و Details و See all events

المطلوب: at least one data table
[✔] أربعة جداول (مذكورة فوق)

المطلوب: at least two forms with appropriate input types and labels
[✔] الفورم الأول: التسجيل      في register.php
    الفورم الثاني: التواصل     في about.php
    كل حقل له <label for="..."> مربوط بـ id الحقل
    الأنواع المستخدمة:
      input type="text"    الاسم والرقم الجامعي
      input type="email"   البريد
      select               اختيار الفعالية
      textarea             نص الرسالة
      input type="submit"  زر الإرسال


ثانياً: CSS
=========================================================

المطلوب: One shared external stylesheet
[✔] ملف واحد فقط: style.css
    مربوط في كل صفحة بـ <link rel="stylesheet" href="style.css">

المطلوب: no inline styles
[✔] لا يوجد أي style="..." داخل أي صفحة

المطلوب: consistent color scheme and typography
[✔] لون واحد #003366 للهيدر والفوتر والعناوين ورؤوس الجداول
    خط واحد Arial في كل الموقع

المطلوب: a styled navigation bar
[✔] وسم <nav> منسّق في style.css
    روابط بلون كحلي مفصولة بعلامة |، وتحته خط فاصل

المطلوب: hover/focus states
[✔] nav a:hover        يتغير اللون للأحمر
    nav a:focus        يتغير اللون للأحمر
    input:focus        خلفية الحقل تتغير لرمادي فاتح
    select:focus  و  textarea:focus  نفس الشي

المطلوب: basic responsive behavior
[✔] @media (max-width: 600px)  في آخر style.css
    الجدول يصير عرض 100%
    حقول الفورم تصير عرض 100%
    المسافات تصغر


ثالثاً: المتطلبات الوظيفية (الصفحات)
=========================================================

1) Home page
   المطلوب: تعريف بالنادي + أقرب 3 فعاليات
   [✔] index.php
       فقرة تعريف + قائمة نشاطات النادي
       أقرب 3 فعاليات بحلقة for من 0 إلى 2

2) Events page
   المطلوب: قائمة بكل الفعاليات مولّدة بـ PHP من مصدر بيانات
   [✔] events.php
       المصدر: مصفوفة PHP في ملف events_data.php
       تُطبع بحلقة foreach داخل جدول

3) Event details page
   المطلوب: صفحة تعرض تفاصيل فعالية مختارة عن طريق GET
   [✔] event.php?id=3
       نقرأ الرقم بـ $_GET["id"]
       ندور عليه بحلقة foreach
       لو الرقم غير موجود تظهر رسالة Event Not Found

4) Registration page
   المطلوب: فورم (اسم، رقم جامعي، إيميل، فعالية) + تحقق في السيرفر
             + حفظ في ملف + رسالة تأكيد
   [✔] register.php
       التحقق:
         - الاسم فاضي
         - الرقم الجامعي فاضي
         - الرقم الجامعي فيه حروف     (is_numeric)
         - الرقم الجامعي مو 9 خانات   (strlen)
         - الإيميل فاضي
         - صيغة الإيميل غلط           (filter_var)
         - ما اختار فعالية
       الحفظ:
         file_put_contents("registrations.txt", $line, FILE_APPEND)
       التأكيد:
         رسالة خضراء باسم الطالب واسم الفعالية

5) Registrations list page
   المطلوب: قراءة التسجيلات المخزنة وعرضها في جدول HTML
   [✔] registrations.php
       file()  لقراءة الملف سطر سطر
       explode("|")  لفصل بيانات كل سطر
       ثم تُعرض في جدول

6) About / Contact page
   المطلوب: أعضاء الفريق + فورم تواصل بتحقق فقط بدون إرسال
   [✔] about.php
       جدول أعضاء الفريق (الأسماء من settings.php)
       فورم تواصل بتحقق: الاسم، الإيميل، الرسالة أقل من 10 حروف
       لا يوجد إرسال إيميل، فقط رسالة تأكيد على الشاشة

أضف صورة واحدة على الأقل قبل التسليم.
